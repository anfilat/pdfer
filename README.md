# PDFer

A simple PDF viewer for your phone. Opens files, remembers where you left off, works offline.

**👉 [Open PDFer](https://anfilat.github.io/pdfer/)**

## Features

- **Open from anywhere** — PDFer appears in Android's "Open with" menu for PDF files
- **Auto-restore** — reopens your last file when you come back
- **Continuous scroll** — all pages in one flow, no page-by-page navigation
- **Rotation** — switch between vertical and horizontal document orientation
- **Zoom** — pinch on mobile, Ctrl+scroll on desktop
- **Scroll lock** — locks one axis so you don't accidentally scroll sideways
- **Offline** — add to your home screen and PDFer works without internet

## How to use

1. Tap **Open PDF** and pick a file
2. Scroll, zoom, rotate — however you like
3. Your position, zoom, and rotation are saved automatically
4. Next time you open PDFer, it picks up right where you left off

## Install on your phone

PDFer is a Progressive Web App. On Android:

1. Open [PDFer](https://anfilat.github.io/pdfer/) in Chrome
2. Tap **Add to Home Screen** in the browser menu
3. PDFer appears as a regular app

Once installed, PDFer also shows up in the system **Open with** menu when you tap a PDF file — just like a native app.

No internet needed — the app and files are cached locally.
